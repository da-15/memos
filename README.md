# memos

メモアプリ「もちメモ」。iPhone のホーム画面に追加して使う PWA です。本体は `/docs` にあります。

## 使い方

1. GitHub Pages の公開元を `main` ブランチの `/docs` にする
2. 公開された URL を iPhone の Safari で開く
3. 共有ボタン →「ホーム画面に追加」

## できること

### 一覧（トップ画面）
- 右下の ＋ で新しいメモを作る。開いた時点でキーボードが出る
- メモは1行目がタイトル、続く2行がプレビュー、右下に更新日時
- タップでメモを開く
- 左にスワイプで削除。下に出る「もどす」で取り消せる（約4.5秒）
- 長押しで持ち上げて、上下にドラッグで並べかえ。画面の端では自動でスクロールする
- 右上の歯車：バックアップのメニュー（下の「バックアップ」を参照）
- パソコンでもマウスで同じ操作ができる（クリックで開く、横にドラッグで削除、長押ししてドラッグで並べかえ）

### メモを書く画面
- 罫線入りの紙に、テキストを書くだけのシンプルな画面
- 自動保存（入力が止まって0.5秒後・戻るとき・アプリを閉じるとき）
- 書いている行は、いつも画面の上から1/3くらいの高さに来る（タップしたときも、改行したときも）
- 戻り方：左上の「もどる」ボタン、画面の左ふちから右へスワイプ、Android の「戻る」、パソコンのブラウザの戻るボタン（どれもブラウザの「戻る」を通るので、同じ動きになる）
- 「あ」ボタン：スライドバーで文字の大きさを 12〜26px に変える。罫線の間隔も一緒に変わる。選んだ大きさはアプリが覚えておく（書く画面だけに効く）
- パレットボタン：メモの色を6色（いちご・レモン・ミント・ラベンダー・ソーダ・ピーチ）から選ぶ。一覧のカードの色も変わる
- 右上の保存の印：うすい丸＝からっぽ、ふわふわする点＝保存中、チェック＝保存済み。保存できないときだけ「⚠ ほぞんできてないよ」と文字で出る

### バックアップ
- **バックアップする：** メモを1つのファイル（`mochimemo-年-月-日.json`）にする。iPhone では共有メニューが出るので、「"ファイル"に保存」で iCloud Drive などに置く。パソコンではダウンロードになる
- **バックアップから戻す：** 保存したファイルを選んで、戻し方をえらぶ
  - いまのメモに たす：バックアップのメモを追加する。同じメモ（同じ ID）は二重にならず、いまのほうを残す
  - まるごと入れかえる：いまのメモをぜんぶ、バックアップの中身にする
  - どちらも、直後に出る「もどす」で元に戻せる
- メニューには、前にバックアップした日とメモの数が出る

## 仕様メモ

- **保存先：** 端末のローカル（`localStorage`）のみ
  - メモ：`mochimemo.v1`（配列。並び順がそのまま一覧の順）
  - 文字の大きさ：`mochimemo.fontsize`
  - 前のバックアップ：`mochimemo.lastBackup`（日時とメモの数）
  - 容量の目安は約5MB（日本語で約250万文字）
- **空のメモ：** 保存しない。戻らずにアプリを閉じても残らない。起動時に、前のバージョンで残った空のメモを片づける
- **既存メモを開いたとき：** キーボードは出さず、読むところから始める（本文をタップで編集）
- **新しいメモの色：** 一番上のメモの次の色を、順番に自動で決める
- **表示：** 明るい画面だけ（ダークモードはなし。iPhone の上の帯の色がモードの切り替えについてこないため、シンプルさを優先してやめた）。背景は淡い緑の水玉
- **オフライン：** service worker（`docs/sw.js`）がアプリ本体をキャッシュする

## ファイル

| ファイル | 中身 |
|---|---|
| `docs/index.html` | アプリ本体（HTML・CSS・JavaScript を1ファイルに） |
| `docs/sw.js` | オフライン用の service worker |
| `docs/manifest.webmanifest` | ホーム画面に追加したときの名前・色・アイコン |
| `docs/icons/` | アプリのアイコン（180・192・512px） |

## 更新するときの注意

- `docs/` の中身を変えたら、**`docs/sw.js` の `CACHE` の名前（`mochimemo-vXX`）の数字を1つ上げる**。上げないと、インストール済みのアプリにオフライン用のファイルが届かない
- ページは毎回 GitHub に確認してから読む（`cache: 'no-cache'`）ので、アプリを開き直せば更新が届く
- アイコンを変えても、ホーム画面のアイコンはすぐには変わらないことがある。そのときはアプリをいったん削除して、もう一度「ホーム画面に追加」する

## iPhone で気をつけること（作りながら分かったこと）

- **隠した要素を表示に切り替えない：** `visibility: hidden` から表示に切り替えた直後の要素は、iOS が文字を描かなかったり、キーボードを出さなかったりする。メモを書く画面は、閉じているあいだも隠さず、画面の右外に置いて `inert` にしている
- **キーボードを出すタイミング：** ＋は、指がふれた瞬間（touchstart）に画面を開き、指をはなした瞬間（touchend）にカーソルを置く
- **キーボードの高さには頼らない：** iPhone が返すキーボードまわりの数値は、起動のしかたやカーソルの位置で毎回変わる。そこで、書いている行（カーソルの行）をいつも画面の上から1/3の高さにスクロールする（タイプライターのような動き）。キーボードより上なので隠れず、iPhone も画面全体をずらさない。メモを書く画面はキーボードの裏まで伸ばしたまま（キーボードの上のバーは透けるため）
- **ページ自体はスクロールさせない：** 一覧だけが専用の枠の中でスクロールする。キーボードの開け閉めで iOS がページをずらしても、一覧がずれない
- **16px 未満の入力欄：** タップすると iOS が画面を勝手に拡大する。viewport に `maximum-scale=1` を入れて止めている（指での拡大はそのままできる）
