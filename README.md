# memos
メモアプリ「もちメモ」（iPhone向けPWA）。本体は `/docs` にあります。

## 使い方
GitHub Pages の公開元を `main` ブランチの `/docs` にして、Safari で開き「ホーム画面に追加」。

## 仕様メモ
- 保存先：端末のローカル（localStorage）のみ
- 保存方法：自動保存（入力停止0.5秒後・戻るとき・アプリを閉じるとき）
- 戻り方：左上「もどる」ボタン、または画面左ふちから右スワイプ
- 既存メモを開いたとき：キーボードは出さず閲覧から始める（本文タップで編集）
- 空のメモは戻ったときに自動で破棄

## 今後の機能候補

- ~~メモの色を選ぶ~~（対応済み：メモを書く画面の色ボタンから）
- 検索
- ピン留め
- チェックリスト
